# Ventris

An idle tower defense game for Android (Galaxy S25 Ultra) set in an abstract dimensional void. You are the tower: a shape that grows from a 0D point through polygons to polyhedra (and maybe a 4D capstone). It's permanent progression only, with no prestige and no upkeep.

- Visual style: pure black with liquid-glass UI. Everything is procedural geometry.
- Status: planning

See [`docs/DESIGN.md`](docs/DESIGN.md) for the full design plan.
